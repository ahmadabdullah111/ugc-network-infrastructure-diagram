# UGC Network Infrastructure Diagram

This repository contains the network infrastructure diagram prepared for UGC. The diagram represents the structured layout of the network including switches, servers, wireless access points, and CCTV connectivity.

## Project Overview
The purpose of this project is to document and visualize the network infrastructure to support network management, troubleshooting, and future expansion planning.

## Network Components
- Core Switch
- Distribution Switches
- Access Switches
- Wireless Access Points
- CCTV Network
- Servers and Storage
- Structured LAN Cabling

## Features
- Clear network topology representation
- Organized infrastructure layout
- Documentation support for network planning
- Scalable network design

## Tools Used
- Microsoft Visio / Draw.io
- GitHub for documentation and version control
